General-Purpose Point of Sale & Inventory System

A full-stack, multi-tenant POS and inventory system for retail, wholesale, distribution, and service businesses — covering the complete commercial loop from purchasing and FIFO stock control to POS checkout, customer/supplier ledgers, payroll, and business reporting. Built to be industry-agnostic so any business can configure it to fit their model. The Problem

Most POS systems are built around one specific industry, forcing unrelated businesses to work around a rigid data model. This system is intentionally not tied to one industry — a business can define its own categories, units of measure, variations, warehouses, customers, suppliers, prices, staff roles, and enabled features, while still getting a complete commercial loop: purchasing, stock control, checkout, ledgers, and reporting. This POS system provides a highly configurable commercial loop, allowing diverse businesses to manage their inventory, suppliers, multi-warehouse stock transfers, payroll, and checkout flows.

Key Features

Multi-Tenant Architecture

Each business is scoped by business_id, enforced automatically at the database layer via a Prisma extension and AsyncLocalStorage-based tenant context — no manual filtering required in any route handler.

Full Purchasing & FIFO Stock

Purchases against suppliers create stock movements, update supplier ledgers, and open FIFO cost lots — which are consumed automatically at the point of sale to maintain accurate cost of goods sold on every invoice.

Point of Sale Checkout

Barcode/SKU search, variant and batch selection, kit sales, and line-level discounts. Supports Cash, Card, UPI, Bank Transfer, and Credit payments — with change calculation and receipt generation.

Warehouse Transfers

Atomic stock transfers between warehouses with complete transfer history for audit purposes. Stock levels update in real time across all warehouses when a transfer is confirmed.

Dynamic Roles & Permissions

Configurable roles with per-user permission overrides, plus a separate platform-admin layer for managing businesses, enabling modules, and controlling admin seat counts.

Reporting, Payroll & Expenses

Dashboard summaries, sales charts, and downloadable PDF reports — plus full payroll processing, commission tracking, and expense-budget management for operational cost control.

System Architecture

01
Frontend Layer

React 19 + Vite + Tailwind CSS

A modern React 19 single-page application built with Vite for fast development and optimized production builds. Communicates with the backend over HTTP/JSON using Bearer JWT authentication. UI includes a full POS screen, inventory management, purchasing flows, reporting dashboards, and payroll panels.

02
Backend Layer

Express 5 REST API — Modular Routers

An Express 5 REST API using Prisma ORM with request-scoped tenant context via AsyncLocalStorage. Exposes dedicated routers for: products, inventory, sales, purchases, credit, payroll, transfers, users, roles, and reporting. All business logic lives in service modules — routes are thin controllers.

03
Database Layer

PostgreSQL — Historical Snapshotting

PostgreSQL with Prisma ORM. Historical sales records snapshot the unit price, discount, and cost of goods sold at time of sale — preserving invoice accuracy even as product prices change over time. FIFO cost lots are tracked per product/batch across all warehouses.

04
Security Layer

JWT Auth + Multi-Tenant Isolation

JWT bearer token authentication with role-based access control. The Prisma tenant extension automatically appends WHERE business_id = ? to all queries for the active tenant — preventing cross-business data leaks at the ORM level, not just in application code.
